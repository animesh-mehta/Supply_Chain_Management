# 📦 Supply Chain Management Dashboard

An interactive, end-to-end dashboard built using **Power BI** and **Excel** to monitor, analyze, and optimize supply chain operations for a fashion and beauty startup.

---

## 🚀 Project Objective

To provide actionable insights across the entire supply chain — from inventory and production to supplier and logistics performance 
— in order to enhance visibility, reduce costs, and support strategic decisions.

---

## 📊 Key Features

- **Executive Overview**: Track KPIs like Total Inventory, Stock Turnover, and Lead Time at a glance.
- **Operational Insights**: Monitor order fulfillment, lead times, and supplier performance.
- **Inventory Management**: Analyze stock levels, inventory holding costs, and turnover rates.
- **Supplier & Logistics Performance**: Evaluate vendor delivery timelines, defect rates, and logistics efficiency.

---

## 📁 Dataset Overview

The dataset includes detailed records of:

- Stock Levels  
- Inventory Costs  
- Production Volume  
- Supplier & Vendor Data  
- Delivery Lead Time  
- Defect & Return Rates  
- Transportation & Logistics Information  

---

## 🛠️ Tools & Technologies

- **Power BI** – Data modeling and dashboard visualization  
- **Excel** – Data cleaning and exploratory analysis  

---

## 🎯 Project Goals

- Centralize supply chain data for real-time monitoring  
- Enhance decision-making through data visualization  
- Improve supplier management with performance metrics  
- Optimize inventory planning and minimize holding costs  
- Reduce lead times and logistics delays  

---


## 🧠 Insights Derived

- Identified top-performing suppliers based on lead time and defect rate  
- Reduced excess inventory by visualizing slow-moving SKUs  
- Improved logistics planning with shipment frequency tracking  
- Streamlined production planning using real-time stock and fulfillment data  

---

## 📌 How to Use

1. Clone the repo or download the `.pbix` file.
2. Connect to the provided Excel/SQL data sources.
3. Refresh the dashboard in Power BI Desktop.
4. Interact with visuals using slicers and filters.
